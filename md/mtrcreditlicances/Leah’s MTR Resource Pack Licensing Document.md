# Leah’s MTR Resource Pack Licensing Document  
All the infomation is copied from [here](https://docs.google.com/document/d/1dKVTrkLRToy3SumLKVXwRNHGqlUlR1w5q92NQ0wICyU/edit?tab=t.0), turned into a Mark down format.
By using this license, you agree that you have followed all the written guidelines that are listed in this document.  
Please note that this license can only be used if you are distributing any content that is in any way related to or using any of the resources from any of Leah’s MTR Resource Packs.

# **Section 1 \- Distribution**

1. Resource packs uploaded that are related to any of Leah’s Resource Packs, are restricted to only contain retextures, vehicle data and any additional resources that you may like to add.  
2. When distributing your retextures, please ensure you link the appropriate resource packs as dependencies.  
3. Sharing your retextures on the discord server is recommended if you wish for your retextures to be seen by others who want to use it.  
4. Leah’s Resource Packs being put into a bigger resource pack is fine as long as you credit Leah wherever possible.

# **Section 2 \- Retextures**

1. You can create whatever you want as long as it follows community guidelines of Modrinth and does not contain the following:  
   1. NSFW  
   2. Gore  
   3. Inappropriate Decals and Pictures  
   4. Sensitive Information  
   5. References to Hate groups and Terrorist groups  
   6. Flashing Lights of extreme intensity  
   7. Swear Words  
   8. Difficult/Trippy visuals  
   9. AI Generated Media  
2. Please refer to the retexture templates to start work on creating retextures.  
3. You can create as many retextures as you’d like for your resource pack.

# **Section 3 \- Attribution**

1. You can only use this license if you are sharing any resource packs that include any resources from Leah’s Resource Packs, the only exception being is if the resource pack also contains other resources besides anything created by Leah which is where you would need to put in both the License of your choice as well as the Leah’s MTR Resource Pack License.  
2. When sharing any retextures on Modrinth, please add Queen\_Leah\_I to the list of creators as “Original Creator” and yourself as “Retexturer”, after that wait for Leah to look at your pack before she sends the project to the reviewal process.  
3. Ensure you are following all the guidelines before using this license in order to better understand what you are doing when sharing your own retextures of Leah’s Resource Packs.

# **Section 4 \- Commercial Use**

1. Resource packs can be made and distributed commercially, as long as they aren’t standalone copies of Leah’s Resource Packs but with additional resources added by you or anyone.  
2. You are free to control the weight of revenue gained between all creators listed on Modrinth as long as it is fair and that all users get the revenue equally.

# **Section 5 \- Media Use**

1. Media including anything from Leah’s Resource Packs, are allowed as long as you credit Leah herself.  
2. Reuploads of Leah’s Media that include her resources are not allowed; however, all material must be original.

# **Section 6 \- Server Usage**
